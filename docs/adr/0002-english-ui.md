# 2. English UI

Date: 2026-10-15

## Status

Accepted

## Context

This is a Hexlet course project, and the course materials and README are in Russian. The first version of the frontend used Russian text as well.

## Decision

All UI text is in English, and the app is called "Call Calendar". The README stays in Russian, because it describes the Hexlet project.

## Consequences

The UI and README are in different languages on purpose. New UI text is written in English, and there is no Russian word to settle for each domain term, so the English names in `GLOSSARY.md` are used in the UI as they are.
